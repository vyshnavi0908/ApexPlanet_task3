# ApexPlanet Task 3 - User Management System

A responsive user management web application developed as part of the ApexPlanet Full Stack Web Development Internship.

## Technologies Used
- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- XAMPP

## Features
- User registration and login
- Secure password hashing
- Session-based authentication
- Role-based access for admins and users
- Admin user management (create, view, edit, delete)
- User profile management
- Profile photo upload
- Form validation
- Responsive user interface

## Local Setup
1. Install XAMPP with Apache, PHP, and MySQL/MariaDB.
2. Place the project folder inside `C:\xampp\htdocs\`.
3. Create the database `apexplanet_task3`.
4. Import `database/schema.sql` using phpMyAdmin.
5. Check the database settings in `config/config.php`.
6. Open `http://localhost/ApexPlanet_Task3_User_Management_System/` in your browser.

## Note
This project runs locally with XAMPP. It is not deployed as a live website.
